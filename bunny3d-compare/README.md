# バニー 3D 比較ビューア

同じ画面で、ちびバニーの実装を ◀ ▶（または左右キー）で見比べられます。

並び（先頭から）:

1. three.js版 v5（コード生成。glb 化せず、元のトゥーン・まばたき・待機モーションのまま）
2. Blender MCP直接版 v5
3. agy手順書版 v0（初回の通し）
4. agy手順書版（仕上げ後の最新）
5. Codex版（Aポーズの立ち姿。すわるポーズは未収録）

立ち／正座は右上の「たつ」「すわる」で切り替えます。Codex版は立ちのみです。

▶ 見る: https://akariyachan.github.io/grok-gemini-games/bunny3d-compare/

モデルの glb と three.js版のコードは、このフォルダ内に実体として置いてあり、相対パスで読み込みます。
