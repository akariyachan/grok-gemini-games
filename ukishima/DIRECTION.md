## 技術要件
- 単一ページ: ukishima/index.html（必要なら同フォルダ内に main.js / style.css を分けてもよい）。ビルド不要。
- three.js は importmap で CDN から読み込む（例: https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js 、addons も同バージョン）。
- UIテキストはすべて日本語。
- スマホ縦持ち（390x844 等）で指一本操作: ドラッグで視点回転、ピンチでズーム、タップで配置/選択。マウスでも遊べる（ドラッグ回転、ホイールズーム、クリック）。タップとドラッグはしっかり区別すること（移動量しきい値）。
- モバイルで軽く動くこと: devicePixelRatio は最大2に制限、ポリゴン少なめ、影は使わないか軽量に、ライトは点光源を大量に使わず発光マテリアル＋スプライト/加算合成グローで表現。
- テスト用フック: window.__game にゲーム状態（state: 'title'|'play'|'paused'|'result', timeLeft, light（総灯り）, islands, bridges, routes, ships, buildings, score）を公開。さらに window.__game.api として、プログラムから操作できる関数を用意すること: placeBuilding(islandId, type, slotIndex), buildBridge(islandA, islandB, high:boolean), removeBridge(bridgeId), buildRoute(islandA, islandB), startGame(), setSpeed(n)（時間倍率、テスト用）。戻り値は成功/失敗理由。URLパラメータ ?fast=1 で時間10倍速。

## 世界
- 夜空に浮かぶ小さな浮島が7〜9個。プレイヤーは中央の1島（灯りあり）からスタート。他の島は近い島（橋が届く距離）と遠い島（船の航路でしか届かない距離）が混在。島は低ポリの岩の塊＋上面の草地、下に雲海。星空、月。
- 各島に建物スロット（4〜6個、上面の円形マーカー）がある。

## 資源とルール
- 「灯り」= 通貨兼スコア。プレイヤーの灯り残高(所持灯り)と、各島が放つ灯り(島の灯り量)を分けて考えてよいが、画面上部に「灯り」の数値を大きく表示。
- 建物（タップでスロット選択→下部メニューから選ぶ）: 各建物に 建築コスト（灯り）と 建築時間（秒）。建築中はスロット上に進捗リング/バーを表示、完成すると光る。例:
  - 家: コスト10 / 6秒 / 毎秒少し灯りを生む
  - 街灯: コスト6 / 3秒 / 周囲を照らし隣接ボーナス
  - 屋台: コスト15 / 8秒 / 隣（近いスロット）に街灯があるとお客が来て灯り生産+50%
  - 灯台: コスト25 / 12秒 / 航路の船の速度アップ or 島の灯り減衰を抑える
  （数値は遊んで調整してよい。ただし建築コストと建築時間が必ず意味を持つこと）
- 隣接コンボ: 屋台×街灯、家×家（町並み）など。コンボ成立時は小さなポップ表示（「お客が来た！ +50%」など）。
- 橋: 隣接（近距離）の島同士を接続。コスト（例20）と建築時間（例5秒）、建築中は橋が端から伸びていく演出。接続された島は灯りとお客が流れ、橋の上に光の粒が流れる（光の道）。接続されていない島には建物を建てられない（または資材が届かない）。橋は選択して「撤去」可能: 撤去には少し灯りがかかる（例5）。
- 高い橋: コスト高（例45）・建築時間長（例9秒）。見た目も高いアーチ。船の航路は高い橋の下をくぐれる。
- 船/航路: 接続済みの島から遠い島へ「航路」を引く（2島を順にタップ）。コスト（例15）。航路は点線で表示。船が実際に航路を往復し、資材/お客を運ぶ（片道数秒〜十数秒の実時間）。船が到着するたびに相手の島が育つ（灯り+、初回到着で島が「つながった」状態になり建築可能に）。
- 重要ルール: 船の航路は通常の橋と交差できない（上から見た2D線分交差判定）。航路を引こうとして通常の橋と交差する場合は「橋が航路をふさいでいます」と表示して不可。逆に航路を横切る通常の橋も架けられない（航路をふさぐため）。高い橋なら交差OK。
- 緊張感: 各島の灯りは時間で少しずつ減衰する（何もしないと損）。船の配送は時間差。これで「すぐ得する橋」vs「時間はかかるが大きく育つ航路」の選択が生まれるように数値を調整。
- 光の道: つながった島のネットワークは、橋と航路に沿って光が流れて見えること。

## 時間と終わり
- リアルタイム。一夜は約5分（300秒）。残り時間を上部に表示（例「夜明けまで 4:32」）。
- 時間経過で空が深い群青→紫→白んだ夜明け色へ徐々に変化。
- 一時停止ボタン（右上）。一時停止中は「再開」「遊び方」「最初から」。
- 夜明け: 時間切れで朝日が昇る演出（地平線から太陽、空が明るくなり、島の灯りが一つずつ消えていく）。その瞬間の総灯り（全島の灯り合計＋所持灯り、定義は分かりやすく画面に明示）がスコア。
- 全島を早期につないだら、その場で夜明け演出、残り時間ボーナス（例 残り秒×2）を加算。
- 結果画面: スコア、内訳（灯り、つないだ島数、残り時間ボーナス）、「もう一夜」ボタン（リトライ）。ベストスコアは localStorage に保存。

## UI
- タイトル画面: タイトル、「はじめる」、「遊び方」。
- 遊び方オーバーレイ: 短く（5〜6行）。操作、建物、橋、高い橋、航路、交差ルール、夜明け。
- 下部に操作パネル: モード切替ボタン「建てる」「橋」「高い橋」「航路」「撤去」、選択中の対象に応じたメニュー（建物一覧はコスト・時間を表示、灯りが足りないものはグレーアウト）。
- 選択できる対象（島、スロット）はタップ時にハイライト。橋モードでは1島目をタップ→架けられる候補の島が光る→2島目をタップ。
- 画面に収まること（縦844px、スクロール不要）。safe-area対応。文字はスマホで読める大きさ。
