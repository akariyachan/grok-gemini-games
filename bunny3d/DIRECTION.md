## 動き・操作
- 待機モーション: 呼吸（胸と肩がゆっくり上下）、うさ耳がぴょこぴょこ揺れる、髪がわずかに揺れる、ときどきまばたき（2〜6秒ごとにランダム）、差し出した手がわずかに揺れる。

- キャラをタップすると反応（耳がぴょこん、照れて頬が赤くなる等、ランダムで1つ）。
- ドラッグで台座ごと左右に回転（慣性つき）、ピンチ/ホイールで少しズーム（範囲制限）。タップとドラッグは移動量しきい値で区別。自動でゆっくり回る「くるくる」トグル。
- 画面上部に小さくタイトル「バニーの3Dフィギュア」と一言（例「本日のご案内」）。UIテキストはすべて日本語。

## Round 4（ブラッシュアップ第4回：表情としぐさを生き生きと可愛く）— 指示原文

```
ブラッシュアップ第4回「表情としぐさを生き生きと可愛く」です。最優先は引き続き「より可愛くなること」。
今の版: /workspace/ss/bunny3d/R3-s01-front.png（立ち正面）、R3-stand.jpg（遷移中・立ち正面・斜め・横・背面・投げキッス）、R3-detail.jpg（座り：ふつう・まばたき・半目・投げキッス・横・背面・タップ反応）。必ず開いて見てください。

## 1. 顔の印象をやさしく（最優先）
- 眉が内側に下がって「怒っている／にらんでいる」ように見える（特に立ち姿の正面）。眉は細くやわらかい弧で、内側をほんの少し上げた「やさしい・ちょっと困り眉」に。目の上に少し離して置く。
- 上まつげの外側のはねを少し控えめにし、目じりを少し下げて、たれ目気味のやさしい目に。
- 半目は「眠そう・とろん」と見えるように（にらみ目に見えないよう、上まぶたのラインを丸く）。
- ほっぺのチークをもう少しだけはっきり、照れ線は細く。

## 2. 表情を増やして生き生きと
- 表情ボタンに「にっこり」（∩∩の閉じ目で大きく口を開けた笑顔）と「てれ」（目をそらして頬を真っ赤に、小さな汗マーク）を追加（全部で6つ。スマホで1行に収まらなければ2行や横スクロールで押しやすく）。
- 口の形も表情ごとに変える（ふつう=にこっと開いた口、半目=小さな ω 口、投げキッス=すぼめた口、てれ=波線の口）。
- 表情の切り替えは瞬間ではなく、目の開閉を0.1〜0.15秒でアニメーションさせる。

## 3. しぐさと待機モーション
- 待機中、数秒〜十数秒ごとにランダムで可愛いしぐさを1つ: 首をかしげる（左右）、差し出した手で小さく手を振る、うさ耳の片方だけぴくっと動く、髪を耳にかけるしぐさ（立ち姿のみ）、ちょっと体を弾ませる。同じしぐさが連続しないように。
- 髪とうさ耳に簡単な二次揺れ（体の動きや回転に少し遅れてついてくるバネの揺れ）を付ける。台座を回したときに髪がふわっと遅れてなびくように。
- タップ反応を増やす: 頭をタップ=耳がぴょこん＋にっこり、体をタップ=てれ顔＋ハートが1つ、手をタップ=ハイタッチのように手がぴょこっと上がる（判定が難しければ当たった位置の高さで頭/体を分ける程度でよい）。
- 一定時間（約20秒）操作がないと、カメラの方を向いて手を振る「こっち見て」アピールを1回。

## 4. 立ち姿をもっと可愛く
- 脚がまっすぐな2本の柱に見える。体重をのせる脚はまっすぐ、反対の脚はひざを軽く曲げて内側に寄せ、つま先を内向きに（内股）。腰を体重側に少し傾ける（コントラポスト）。
- 脚の形は太ももは丸く、ひざ下からくるぶしに向かって細くなるように。網タイツの網目がスマホでも見えるように（肌色がやや白飛びしていて網が薄い）。
- 立ち姿の腰に添えた側の手（画面左）が体に埋もれ気味なので、腰に軽く手を当てる形をはっきり見せるか、体の前で手を軽く握る形に。

## 条件
- ドローコールは今の83程度から大きく増やさない（90以下）。三角形数は6万以下。
- 既存のテストフック（window.__bunny とその api、?expr=/?freeze=/?rot=/?zoom=/?pose=、setPose）は維持。setExpression は新しい 'smile'（にっこり）と 'shy'（てれ）も受け付ける。?freeze=1 のときはランダムなしぐさも止める。コンソールエラー0。
- bunny3d/ の外は変更しない。git commit/push はしない。
- スマホ（390x844）とPC（1280x800）で、すわる・たつ それぞれ全表情のスクリーンショットを撮り、「可愛いか？」「怖く/怒って見えないか？」を基準に直してから終えてください。
- 最後に変更点を短く日本語でまとめてください。
```

## Round 5（ブラッシュアップ第5回：仕上げ：光と輪郭・登場演出・スマホでの軽さ）— 指示原文

```
ブラッシュアップ第5回（最終回）「仕上げ：光と輪郭・登場演出・スマホでの軽さ」です。最優先は引き続き「より可愛くなること」。
今の版: /workspace/ss/bunny3d/R4-faces.jpg（座り：ふつう・まばたき・半目・投げキッス・にっこり・てれ・タップ反応）、R4-stand.jpg（立ち：遷移中・正面・斜め・こっち見て・横・投げキッス）、R4-m01-front.png、R4-s01-front.png。必ず開いて見てください。第4回で顔はとても可愛くなりました。今回は全体の仕上げです。

## 1. 光と輪郭（可愛く見える質感）
- パステル寄りのやさしいトゥーン: 影色は紫〜ピンク寄りで、肌の影が灰色っぽくならないように。顔は影を弱めて明るく（顔だけ影の段を1段少なく、またはライトの影響を弱める）。
- リムライト（後ろからの淡いピンク〜ラベンダーの縁の光）を髪・肩・うさ耳にうっすら。回転させたときにきれいに見えるように。
- 輪郭線の太さをパーツ間でそろえる（顔の輪郭は細め、髪の外側はやや太め、指など細いパーツは細く）。カメラとの距離で線が太りすぎないよう、ズーム時も自然に。
- 髪のツヤ（天使の輪）を、頭頂部の帯としてもう少しはっきり、でも上品に。
- 背景のキラキラ（ボケ）を少しだけゆっくり瞬かせ、台座の縁にうっすら光るラインを。

## 2. 登場演出と「撮影」
- ページを開いたとき: 読み込み中は小さな「よみこみ中…」とうさ耳アイコンのくるくる。表示されたら、キャラが台座の上にぴょこんと現れて（小さく→ふわっと元の大きさに、ちょっと弾む）、うさ耳がはねてキラキラ、にっこり→ご案内の手、の約1.5秒の登場演出。
- 「📷 撮影」ボタン: いまの画面（UIなし、キャラと背景だけ）を PNG で保存（ダウンロード）。保存のときシャッターの白いフラッシュを一瞬。ファイル名は bunny3d-日付.png。
- 撮影ボタンは右上の「くるくる」「すわる／たつ」と同じ並びに、押しやすく。

## 3. スマホでの軽さ・見やすさ
- 自動画質調整: 最初の2秒の平均fpsが45未満なら devicePixelRatio を1.5→1.0の順に下げる（window.__bunny.quality に 'high'|'mid'|'low' を公開、?quality=low で固定）。
- タブが非表示のとき（visibilitychange）は描画を止める。
- 静止しているパーツ（台座など）のジオメトリ/マテリアルを統合して、ドローコールを今の83から75以下に減らす（見た目は変えない）。
- prefers-reduced-motion のときは、ランダムなしぐさとキラキラを控えめに。
- 表情ボタンが2行になって画面下を広く占めている。1行の横スクロール（またはアイコン＋短い文字の小さめボタン）にして、キャラの表示領域を広く。スクロールできることが分かるように右端を少しフェード。操作説明の一行は、最初の数秒だけ出して消す。

## 4. 最後の可愛さチェック
- 座り・立ちの全表情を見て、少しでも怖く見える／崩れて見える角度や表情があれば直す（特に横・背面での髪のすき間、手の形、眉）。
- 立ち姿で腰に添えた手と、ご案内の手の指先がきれいに見えるように。

## 条件
- 既存のテストフック（window.__bunny とその api、?expr=/?freeze=/?rot=/?zoom=/?pose=、setPose、setExpression の全6表情）は維持。?freeze=1 のときは登場演出をスキップしてすぐ通常表示に。api.snapshot() で撮影と同じPNGの dataURL を返す関数も追加。コンソールエラー0。
- 三角形数は6万以下。bunny3d/ の外は変更しない。git commit/push はしない。
- スマホ（390x844）とPC（1280x800）で、登場演出の途中・座り・立ち・各表情・撮影フラッシュのスクリーンショットを撮り、「可愛いか？」を基準に直してから終えてください。
- 最後に変更点を短く日本語でまとめてください。
```
