# ことわざクラッシュ ディレクション記録

Grok Bot（ゲームディレクター）が **Claude Opus 5.5（effort: medium、Claude Code CLI）** に送った指示を、各回そのまま記録します。今作はこれまでの Gemini（Antigravity CLI）ではなく Claude Code で実装しています。

## 初回制作

### 初回制作：初版の実装（原文）

**狙い:** 落ちてくるひらがなをなぞってことわざを完成させる核の遊びと、ことわざごとのご褒美演出、テンポのよい即リトライ、テスト用の ?bot=1 自動プレイを1ファイルで作る。

```
カレントディレクトリに、単一の自己完結ファイル index.html を作成してください（canvas + vanilla JS、外部アセット・フォント・ライブラリ・ネットワーク通信なし。404が出ないようにインラインSVGのdata-URIファビコンを入れる）。ブラウザミニゲーム「ことわざクラッシュ」、UIテキストは日本語。カレントディレクトリの外は触らない。git commit/push はしない。ブラウザを起動して自分でテストする必要はありません（こちらでヘッドレス確認します）。
設計ターゲット: 縦持ちスマホ・指1本（メインのテストサイズは 390x844）。PC（マウスドラッグ）と横持ち（縦長のプレイ列を中央に置き、左右はレターボックス）でも遊べること。
コンセプト: 上から落ちてくるひらがなのタイルを、指でスワイプしてつなぎ、ことわざを完成させる。テンポ最優先：つないで離した瞬間に判定・消去・演出が始まり、待ち時間が少ない。
コア:
- devicePixelRatio対応のレスポンシブ全画面canvas。入力はpointerdown/move/up（preventDefault、スクロール/ズーム/長押しメニュー無効）。
- 画面上部に「お題」のことわざを表示（例「ねこにこばん」）。ひらがなタイルは格子状の盤面（例 6列）に上から落ちてきて積もる（落ち物パズル風）。お題の文字は必ず盤面に揃うよう出現を調整し、混ぜ物の文字も出す。
- 隣接（8方向）するタイルを指でなぞってつなぐ。なぞり中はつながった文字列を線と大きな文字で表示。なぞった文字列が お題 と一致したら完成：タイルが弾けて消え、上のタイルが落ちて詰まる、スコア加算、次のお題へ。お題の先頭からの部分一致（2文字以上）でも小さな得点とタイル消去（コンボ的に）を認める。一致しない並びで離したら何も消えず軽いブブー音。
- ことわざごとのご褒美演出（完成時1〜1.5秒、操作は止めない）: 例 ねこにこばん→画面中に小判が降る、ぶたにしんじゅ→真珠がきらきら、さるもきからおちる→猿が落ちてくる、いぬもあるけばぼうにあたる→棒が飛んでくる、はなよりだんご→団子が降る、おににかなぼう→金棒ドーン、ちりもつもればやまとなる→山がせり上がる、など最低10個。各ことわざに短い意味の一言も完成時に表示。
- タイルは一定間隔で新しい行がせり上がる／落ちてくる。盤面が一番上まで埋まったらゲームオーバー。時間とともに落下が速くなる。
- スコア、ベストはlocalStorage（キー 'kotowazaCrushBest'）。HUD: 上部にお題、スコア、ベスト。
- タイトル画面: 「ことわざクラッシュ」「タップでスタート」、1行の遊び方。ゲームオーバー画面: スコア、ベスト、NEW BEST!、完成させたことわざ数、「タップでリトライ」（0.5秒入力無視後、ワンタップで即リトライ）。
- 左上に「← ゲーム一覧」リンク（href="../"）、タイトル文字と重ならない位置。短いWebAudio効果音（なぞり中に1文字ごと音程上昇、完成ファンファーレ、ブブー）と小さなミュートボタン（localStorage保存）。AudioContextは最初の操作で作成。
- requestAnimationFrame、deltaTimeクランプ。コンソールエラーなし。
- テスト用フック: window.__game = {state:'title'|'play'|'over', score, best, solved(完成数), target(お題)} を毎フレーム更新。URLに ?bot=1 があるときは自動プレイ: 盤面からお題の経路を探してポインタ操作を模してなぞる（1文字0.15秒程度）。たまに失敗してだいたい1〜3分でゲームオーバーになるようにする。タイトルから自動で開始し、ゲームオーバー後は2秒待ってリトライ。
最後に作ったものを簡潔にまとめてください。
```

### バグ修正（初回制作のあと）

**狙い:** ヘッドレス確認で見つかった、横持ちで盤面が極小になる問題・意味カードが盤面に重なる問題・自動プレイが強すぎて終わらない問題を直す。

```
index.html のバグ修正をしてください。新機能は追加しないでください。カレントディレクトリの外は触らない、git commit/push はしない。ブラウザを起動して自分でテストする必要はありません（こちらでヘッドレス確認します）。
1. 横持ち 844x390 で盤面がとても小さい（幅約150px、タイルの文字がほぼ読めない）。お題・HUDの縦の占有を減らし、盤面を画面の高さいっぱい近くまで使って縦長のプレイ列を最大化する（横持ちではお題をコンパクトにする等）。タイルは最低でも約36px角を確保。
2. 横持ちで、完成時の「意味」カード（例「馬の耳に念仏」）が盤面の下部に重なってタイルを隠す。カードはプレイ列の中で盤面と重ならない位置に置くか、半透明・小さくして上部に出し、タイルの操作を邪魔しない。縦持ちでもタイルに重ならないことを確認。
3. 自動プレイ(?bot=1)が強すぎて、390x844 と 844x390 で90秒以上ゲームオーバーにならない。指定どおりだいたい1〜3分でゲームオーバーになるよう、時間が経つほど失敗率・迷い時間を上げる（テスト用なので最終的に必ず負ける）。
コンソールエラー0のまま。最後に修正点を簡潔にまとめて。
```
